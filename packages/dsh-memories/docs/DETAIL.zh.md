# 跨会话记忆

把会话里值得长期保留的内容（偏好、决定、踩坑、承诺）抽取成条目，按项目/会话作用域存进记忆库；后续会话按相关度召回并注入上下文。

## 主要能力
  - 抽取：按阶段对会话做抽取与合并，条目带类型、来源与时间。
  - 召回：按语义相关度与时间衰减挑选条目注入，可查看命中原因。
  - 远端命名空间：向浏览器暴露 8 个方法，设置页可浏览、编辑、归档条目。
  - 合并子代理：memories-consolidator 预设，用无工具子代理做去重与合并。

## 常用入口
  - 设置 → 记忆：浏览、搜索、归档、导入导出。
  - /memories 命令：查看与整理记忆库状态。

## 注意
  - 合并任务只在会话空闲时触发；需要立刻跑用 /memories consolidate。
  - 记忆库按项目作用域分目录；搬会话不会自动带记忆条目（需要显式搬）。
