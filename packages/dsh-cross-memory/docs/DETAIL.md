# Cross-memory

Extracts whatever is worth keeping (preferences, decisions, pitfalls, promises) into scoped memory entries and recalls the relevant ones into later sessions.

## Capabilities
  - Extraction and consolidation passes with type, source and time on every entry.
  - Recall ranked by relevance with time decay; hit reasons are inspectable.
  - A Remote namespace (8 methods) for browsing and editing from settings.
  - A tool-free memories-consolidator child preset for dedupe and merge.

## Notes
  - Consolidation runs when the session is idle; /memories consolidate forces it.
  - Entries are scoped per project; moving a session does not move memories automatically.
